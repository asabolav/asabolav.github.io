Google
google.com — World's most indexed search engine with the most powerful operator set
45 operators
Site & URL Operators
site:
Restrict results to a specific domain or subdomain. Works with or without www.
→ site:gov.uk filetype:pdf
Recon
inurl:
Match pages with a keyword in the URL path or parameters.
→ inurl:admin inurl:login
Recon
allinurl:
All specified keywords must appear in the URL. Equivalent to multiple inurl: operators.
→ allinurl:admin login php
Recon
related:
Find websites similar or related to the specified URL. Great for competitive analysis.
→ related:nytimes.com
OSINT
cache:
View Google's cached snapshot of a page. Useful for removed or modified content.
→ cache:example.com/page
OSINT
info:
Show information Google has about a specific URL including cache and related pages.
→ info:github.com
OSINT
Title & Content Operators
intitle:
Pages with a keyword in the HTML title tag. Use quotes for exact phrases.
→ intitle:"index of" "parent directory"
Recon
allintitle:
All specified words must appear in the page title.
→ allintitle:login admin panel
Recon
intext:
Find pages with specific text in the body content of the page.
→ intext:"confidential" site:company.com
Content
allintext:
All specified words must appear in the body text of the page.
→ allintext:username password login
Content
inanchor:
Pages that have other pages linking to them using specified anchor text.
→ inanchor:"click here" filetype:pdf
Content
allinanchor:
All specified words must appear in anchor text of links pointing to pages.
→ allinanchor:download free software
Content
File & Type Operators
filetype:
Filter by file extension. Supports pdf, doc, xls, ppt, txt, csv, xml, json, sql, log, env, bak, and more.
→ filetype:sql site:github.com
Files
ext:
Alias for filetype:. Filters results to a specific file extension.
→ ext:env "DB_PASSWORD"
Files
Boolean & Logic Operators
\"phrase\"
Exact phrase match. Forces Google to find results containing the exact quoted string.
→ "password" "username" filetype:txt
Filter
-
Exclude pages containing a specific word or phrase. Use before any term.
→ site:example.com -inurl:www
Filter
OR
Return results containing either term. Must be uppercase. Can also use pipe symbol |.
→ site:reddit.com OR site:quora.com "topic"
Filter
AND
Both terms must appear. Default behavior but explicit AND clarifies complex queries.
→ inurl:admin AND inurl:login
Filter
*
Wildcard operator. Matches any word or phrase within a quoted string.
→ "the * of the year" award
Filter
( )
Group operators to control logic precedence in complex queries.
→ (admin OR login) site:example.com
Filter
..
Number range operator. Search for results within a numeric range.
→ camera $200..$500
Filter
Date & Time Operators
after:
Show results indexed or published after a specific date. Format: YYYY-MM-DD.
→ site:example.com after:2024-01-01
Filter
before:
Show results indexed or published before a specific date. Format: YYYY-MM-DD.
→ topic before:2020-01-01
Filter

Shodan
shodan.io — Search engine for internet-connected devices, services, and banners
32 operators
Network & Host Operators
hostname:
Find devices with a specific hostname or domain. Supports partial matching.
→ hostname:.microsoft.com
Network
port:
Find devices with a specific port open. Common ports: 22 (SSH), 80 (HTTP), 443 (HTTPS), 3389 (RDP), 21 (FTP).
→ port:3389 country:US
Network
ip:
Search for devices with a specific IP address or CIDR range.
→ ip:8.8.8.0/24
Network
net:
Search devices within a specific IP range or CIDR block.
→ net:104.16.0.0/12
Network
asn:
Search within an Autonomous System Number (ASN). Great for finding all devices of an organization.
→ asn:AS15169 (Google's ASN)
Network
org:
Find devices registered to a specific organization in WHOIS records.
→ org:"Amazon" port:443
Network
isp:
Find devices from a specific ISP (Internet Service Provider).
→ isp:"Comcast" port:8080
Network
Geographic Operators
country:
Filter by 2-letter ISO country code. US, GB, DE, CN, RU, FR, JP, etc.
→ port:22 country:CN product:OpenSSH
Filter
city:
Filter by city name. Use quotes for multi-word city names.
→ city:"San Francisco" port:27017
Filter
region:
Filter by state or region name.
→ country:US region:"Texas" port:3306
Filter
geo:
Search by geographic coordinates with optional radius in km. Format: lat,lon,radius.
→ geo:37.77,-122.41,50
Filter
Software & Service Operators
os:
Filter by operating system detected in banner. Windows, Linux, Android, etc.
→ os:"Windows Server 2019" port:3389
Recon
product:
Filter by software/product name identified in the service banner.
→ product:"nginx" country:US
Recon
version:
Filter by software version. Excellent for finding specific vulnerable versions.
→ product:Apache version:2.4.49
Recon
http.title:
Find servers with a specific HTML page title. Excellent for finding specific applications.
→ http.title:"Grafana" port:3000
Recon
http.html:
Search within HTTP response bodies for specific text content.
→ http.html:"phpMyAdmin" country:US
Content
http.status:
Filter by HTTP status code (200, 301, 401, 403, 500, etc.).
→ http.status:200 http.title:"Dashboard"
Filter
http.component:
Find servers running a specific web technology component.
→ http.component:"WordPress" country:DE
Recon
http.server:
Filter by the HTTP Server header value returned by the web server.
→ http.server:"Apache/2.2" country:US
Recon
SSL / TLS Operators
ssl:
Find devices with a specific value in SSL certificate fields (CN, SAN, issuer, etc.).
→ ssl:"google.com" port:443
Network
ssl.cert.subject.cn:
Find devices by their SSL certificate Common Name (CN) field.
→ ssl.cert.subject.cn:"*.example.com"
Network

Filter by the certificate issuer (CA). Useful for finding self-signed certs or specific CAs.
→ ssl.cert.issuer.cn:"Let's Encrypt"
Network

Find devices with expired SSL certificates. Values: true or false.
→ ssl.cert.expired:true port:443
Network

→ has_screenshot:true port:5900 country:US
Advanced

Find devices affected by a specific CVE (requires paid Shodan membership).

Advanced

Filter by Shodan-assigned tags: ics, scada, webcam, honeypot, cloud, tor, etc.

Filter

GitHub Code Search
github.com/search — Search across billions of lines of public code and repositories
28 operators
Code Search Operators
filename:
Search for files with a specific name. Case-insensitive partial matching.
→ filename:config.php "password"
Files
extension:
Filter by file extension. More precise than filename: for extension-only searches.
→ extension:pem "BEGIN RSA PRIVATE KEY"
Files
path:
Search within a specific file path. Supports partial matching and glob patterns.
→ path:.github/workflows secret
Recon
language:
Filter results by programming language. Supports all GitHub-detected languages.
→ language:javascript "api_key" filename:.js
Filter
content:
Search within file content. Equivalent to the default text search in code search.
→ content:"secret_key" extension:py
Content
symbol:
Search for function, method, or class definitions by symbol name.
→ symbol:authenticate language:python
Content
Repository Operators
repo:
Search within a specific repository. Requires owner/repo-name format.
→ repo:torvalds/linux filename:Makefile
Filter
org:
Search all repositories belonging to a GitHub organization.
→ org:microsoft language:python "key"
Recon
user:
Search all repositories owned by a specific GitHub user.
→ user:defunkt filename:.env
Recon
stars:
Filter repos by star count. Supports >, <, >=, <=, and ranges (100..500).
→ language:go stars:>5000 topic:api
Filter
forks:
Filter repositories by fork count. Supports comparison operators.
→ forks:>500 language:javascript
Filter
size:
Filter repos by size in kilobytes. Supports comparison operators.
→ size:>10000 language:python
Filter
topic:
Filter repositories by GitHub topic tags.
→ topic:security topic:osint stars:>100
Filter
pushed:
Filter by last push date. Finds recently updated repositories.
→ topic:osint pushed:>2024-06-01
Filter
created:
Filter by repository creation date. Supports comparison operators.
→ created:2024-01-01..2024-12-31 language:rust
Filter
is:
Filter by repo visibility or state. Values: public, private, archived, fork, mirror.
→ is:public org:company topic:internal
Filter
archived:
Filter repositories by archived status. Values: true or false.
→ archived:false org:google language:go
Filter
in:
Specify where to search: name, description, topics, readme. Can be combined.
→ password in:file,path extension:yml
Advanced
Issue & PR Search Operators
is:issue
Filter search results to only issues (not pull requests).

Filter

Filter to pull requests only. Combine with is:open, is:merged, is:closed.
